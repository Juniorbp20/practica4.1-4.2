# Práctica de Matemática Discreta · 4.1 y 4.2

Página web para practicar las Prácticas 4.1 (producto cartesiano y relaciones binarias) y 4.2 (equivalencia, particiones y orden).

- Preguntas de selección múltiple, verdadero o falso, y completar.
- Se elige la práctica, la dificultad y la cantidad de preguntas.
- Al final se genera un reporte que se puede imprimir, descargar o copiar.

Es una página estática: todo está en `index.html`, sin build ni dependencias.
